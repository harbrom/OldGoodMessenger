# Research notes

Use this directory for focused investigations that inform approved work. No
research findings or compatibility tests have been completed in this foundation.

Useful initial topics include:

- Windows XP SP3–11 toolchain and GUI feasibility, footprint, and packaging.
- Sony Ericsson K750i Java ME capabilities and resource limits.
- Unicode counting and text handling across the target clients.
- Protocol, transport, server language, and storage candidates.
- Legacy-compatible authentication and session mechanisms.
- Kolobok emoticon licensing and redistribution permission.
- Invisible-safe status measurement and concurrent-session presence.

For each investigation, state the question, sources and access dates, actual
environment or device tested, method, results, limitations, and open questions.
Distinguish verified evidence from hypotheses. Verify external links before
including them. Do not download competitor source code without explicit
authorization.

Research does not approve architecture. Submit material choices through
[`../decisions/`](../decisions/) before dependent implementation.
